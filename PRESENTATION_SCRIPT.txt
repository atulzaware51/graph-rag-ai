GraphSheet AI - Short Presentation Script

Hello everyone. Today I’ll explain how GraphSheet AI helps people ask questions about spreadsheet data.

First, a user uploads a CSV or Excel file. The app reads the rows and columns, 
saves the spreadsheet data, and prepares it for searching.

To make the content easier to search, the app turns rows into short text chunks. Each chunk is 
about 1,000 characters, and 
nearby chunks can share up to 150 characters so useful information is not lost at the edges. Each chunk keeps details like its source rows and column names.

The app then creates a numerical meaning representation,
 called an embedding, for each chunk. It uses the local Sentence Transformers model all-MiniLM-L6-v2 
 by default. These embeddings are saved in the SQLite database alongside the chunks. 
 So, the project has a simple local vector store; it does not depend on services like FAISS or Chroma.

The app also builds a knowledge graph. 
Think of it as a map: datasets and columns are nodes, and links show how they relate. 
The graph also keeps evidence chunks connected to their dataset. 
It can suggest links between columns in different files when their names and values look similar, but those suggestions are not guaranteed relationships.

When someone asks a question, GraphSheet AI searches for useful chunks by meaning
 and by matching words. It also checks the graph to find relevant columns and possible 
 connections. For a general question, it gives this evidence and graph context
  to an AI model to write an answer.

For questions that need calculations, filtering, or ranking,
 the app can create SQL using the selected spreadsheet columns. 
 It runs that SQL in read-only mode against the selected data, then uses the results to
  answer. This helps keep calculations tied to the actual spreadsheet.

By default, the data, chunks, embeddings, and graph are stored in the local file data/graphsheet.db. In short, GraphSheet AI combines spreadsheet data, search, a relationship map, and carefully limited SQL to make spreadsheet questions easier to answer.

Thank you.
